## Overview

Coolutils PDF Splitter is a Windows utility for turning oversized PDF documents into smaller, organized files. It provides several ways to control the result, including page-range selection, bookmark-based division, and file-size targets, for practical document preparation and archiving tasks.

Batch support allows several PDFs to be processed as part of one operation rather than handled individually. The application also combines multilingual interface support, a responsive UI, reusable output profiles, AI-assisted split-point identification, and content-based naming to streamline larger document jobs.

## How to Use

Start by selecting the rule that should determine where the PDF is divided. The selected method can be applied to a single document or to a group of PDFs processed together.

Possible workflows include:

- Separate a report into sections with page ranges
- Divide a document wherever its bookmarks indicate
- Produce smaller output files using size targets
- Repeat identical split settings across multiple PDFs
- Store frequently used settings in an output profile
- Keep exported files organized with content-based names

### Basic workflow

1. Add one or more PDF files.
2. Choose a splitting method.
3. Modify the output profile when necessary.
4. Check the output settings.
5. Start processing and export the resulting files.

## Settings and Output Profiles

The application's in-app options and output profiles control configuration. When a particular set of split rules is used regularly, save those settings as a profile for quicker reuse.

Example profile layout:

    {
      "split_method": "page_range",
      "batch_processing": true,
      "output_profile": "standard",
      "rename_mode": "content_based"
    }

Depending on the build, configuration data may be stored in the application directory or in the Windows user profile location supplied by the installer.
